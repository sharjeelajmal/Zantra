# Zantrra

**Trust Every Transaction.**

Zantrra is an investor-ready landing page and interactive product demo for a secure commerce platform built for Guinea and West Africa. It showcases escrow-protected peer-to-peer trade, service bidding, mobile-money-ready GNF wallets, and AI-powered fraud protection.

## The Problem

Across Guinea and West Africa, buyers often pay upfront via mobile money with no delivery guarantee. Informal P2P commerce lacks trust rails — fake listings, unverified vendors, and payment disputes cost communities millions annually. Zantrra addresses this with escrow-first infrastructure.

## What It Does

- **Escrow vault** — Funds stay locked in GNF until the buyer confirms delivery
- **6-digit completion code** — Private proof-of-delivery before payment release
- **Service bidding** — Post procurement requests and compare bids from verified local vendors
- **Buy direct** — Fixed-price purchases with instant escrow lock
- **Interactive demo** — Full buyer/seller flow with simulated network latency

## Live Demo Flow

1. **Start** — Buy direct or post a service request  
2. **Bids** — Compare offers from Guinea vendors (cement, paint, bulk food)  
3. **Escrow** — Funds secured in vault; 6-digit code generated  
4. **Deliver** — Seller marks order complete  
5. **Release** — Buyer enters code to release payment to wallet
